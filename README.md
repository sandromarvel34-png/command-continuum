Há apenas uma melhoria que eu acrescentaria além desse prompt: peça explicitamente para a IA não reutilizar a mesma copy da página principal. A página do livro e a página de upsell devem parecer partes de uma mesma jornada, mas cada uma precisa ter um objetivo psicológico diferente. A primeira convence o visitante a comprar; a segunda convence quem já comprou a acelerar seus resultados. Essa distinção costuma ser um dos fatores que mais influenciam a taxa de aceitação do upsell.
